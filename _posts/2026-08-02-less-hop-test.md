Hvor [Hoptest-batteriet](/hoptest-batteriet/) måler din *kvantitative* præstation (hvor langt og hvor hurtigt du kan hinke), måler **LESS-testen (Landing Error Scoring System)** din *kvalitative* bevægelseskontrol.

LESS-testen er et af de mest anerkendte kliniske redskaber til at afsløre uhensigtsmæssige bevægelsemønstre ved landinger – med særligt fokus på **knævalgus** (når knæet falder indad i "streg-stilling"). 

Testen bruges af fysioterapeuter og atleter til både **skadesforebyggende screening** og som en fast del af en **Return to Sport-evaluering** efter en korsbåndsskade (ACL).

---

## Hvorfor er landingsteknik så afgørende?

De fleste overrevne korsbånd og meniskskader opstår ikke ved direkte kontakt med en modstander, men i **kontaktløse situationer** (non-contact injuries) – typisk under en landing efter et hop eller ved et pludseligt retningsskift.

Når du lander med et stift knæ og overkroppen oprejst, overføres hele stødet direkte til ledbånd og ledkapsler i stedet for at blive absorberet af musklerne (fysisk stødabsorbering). Hvis knæet samtidigt falder indad mod midterlinjen (*dynamisk valgus*), udsættes det forreste korsbånd for et vrid, der markant øger risikoen for en alvorlig skade.

> **LESS-princippet:** Testen registrerer, hvor mange biomekaniske "fejl" du begår i en standardiseret hop-landingsøvelse. **Færre fejl = lavere skadesrisiko.**

## Opstilling og Udførelse af LESS-testen

For at udføre testen korrekt opstilles en standardiseret testbane:

### Udstyr
1. **En kasse eller bænk** med en højde på **30 cm**.
2. **En landingslinje** placeret i en afstand svarende til **50 % af atletens kropshøjde** fra kassens forkant.
3. **To kameraer (eller smartphones):** Et placeret direkte **forfra** og et placeret direkte **fra siden** (eller én smartphone, hvor testen udføres ad to omgange).

<pre>
 ┌────────┐
 │ Kasse  │ (30 cm høj)
 └───┬────┘
     │
     │  <--- Afstand: 50% af kropshøjde
     ▼
 ┌────────┐
 │Landings│ <-- Begge fødder lander samtidig her
 └───┬────┘     og afsættes med det samme til et maks vertikalt hop!
     ▼
</pre>

### Sådan udføres testen
1. Atleten står oven på den 30 cm høje kasse.
2. Atleten hopper fremad fra kassen og lander med **begge fødder samtidig** ud over landingslinjen.
3. **Maksimalt hop:** I det øjeblik fødderne rører gulvet, skal atleten med det samme eksplodere lodret op i et maksimalt vertikalt hop (som om man vil gribe en bold i luften).
4. Der udføres typisk **3 godkendte forsøg**, som optages på video til efterfølgende analyse.

## Scoringsskema: De 17 Fejlkriterier

I LESS-testen gennemgås optagelserne billede for billede (eller i slowmotion). Der gives **1 point for hver fejl**, der observeres.

Fejlene opdeles i tre faser: *Første kontakt med gulvet (Initial Contact)*, *Maksimal knæbøjning (Max Flexion)* og *Overordnet helhedsindtryk*.

| Kategori | Fejlkriterium | Hvornår tildeles 1 fejlpoint? |
| :--- | :--- | :--- |
| **Landingskontakt** | **1. Ankel/fodsættelse** | Foden lander fladt eller med hælen først (i stedet for tæerne/forfoden først). |
| | **2. Fodstilling (Rotation)** | Foden er roteret mere end 30° indad eller udad ved kontakt. |
| | **3. Fodafstand** | Fødderne lander enten smallere end skuldrene eller bredere end skuldrene. |
| | **4. Asymmetrisk landing** | Den ene fod rører gulvet markant før den anden. |
| | **5. Knæfleksion** | Knæet er bøjet mindre end 30° ved første kontakt (for stift knæ). |
| | **6. Knævalgus** | Knæet er placeret medialt i forhold til storetåen (falder indad). |
| | **7. Sidebøjning i overkrop** | Overkroppen hælder ud til siden ved landingen. |
| | **8. Hoftefleksion** | Hoften er bøjet mindre end 30° ved første kontakt. |
| **Maksimal bøjning** | **9. Knæfleksion (Dybde)** | Knæet opnår mindre end 45° samlet bøjning igennem landingen. |
| | **10. Knævalgus (Dynamisk)** | Knæet bevæger sig markant indad under stødabsorberingen. |
| | **11. Hoftefleksion (Dybde)** | Overkroppen/hoften bøjes næsten ikke fremad under stødabsorberingen. |
| | **12. Overkropsfleksion** | Ryggen holdes helt stiv/oprejst uden fremadheldning. |
| **Bevægelses-plan** | **13. Ankel/Forfod** | Hælen rører aldrig gulvet (for stiv ankel) ELLER lander tungt på hælen. |
| | **14. Knævalgus-udslag** | Knæet bevæger sig indad med mere end 10 cm sammenlignet med udgangsstillingen. |
| **Helhedsindtryk** | **15. Stødabsorbering** | Landingen fremstår stiv, hård og støjende (0 point = blød, lydløs bøjning). |
| | **16. Samlet bevægelse** | Bevægelsen er stiv eller ukontrolleret. |
| | **17. Samlet samspil** | Visuel vurdering af om atleten fremstår risikofyldt i sin landing. |

---

## Tolkning af din LESS-score

Når alle 17 kriterier er gennemgået på dine videooptagelser, lægges antallet af fejl sammen:

| Samlet fejlscore | Kategori | Klinisk betydning / Skadesrisiko |
| :--- | :--- | :--- |
| **$\le 4$ fejl** | **Fremragende** | Fremragende landingsmekanik. Lav risiko for kontaktløse knæskader. |
| **$5 - 6$ fejl** | **God** | Acceptabel kontrol, men med plads til mindre forbedringer. |
| **$7 - 8$ fejl** | **Moderat** | Moderat uhensigtsmæssig teknik. Anbefales neuromuskulær korrektion. |
| **$> 8$ fejl** | **Dårlig / Høj risiko** | Betydelig fejlmekanik (stive knæ/valgus). **Høj risiko for ACL-skade**. |

> **Skæringsdato for Return to Sport:** I de fleste moderne genoptræningsprotokoller efter en korsbåndskonstruktion kræves en LESS-score på **$\le 5$ point** kombineret med et [LSI på $\ge 90\%$](/hoptest-batteriet/), før atleten må deltage i kontaktsport igen.

## Opsamling og næste skridt

LESS-testen er det ultimative redskab til at spotte de "usynlige" fejl i din teknik, som traditionelle afstandsmålinger ikke fanger. Hvis din score viser moderat eller høj risiko, bør din træning suppleres med fokuserede landingsøvelser, styrke af gluteus-muskulaturen og squat-varianter med elastik om knæene (*feed the mistake*).

* **Test din præstation:** Kombinér LESS med det komplette [Hoptest-batteri (LSI)](/hoptest-batteriet/).
* **Tjek din vertikale spændstighed:** Prøv vores [Guide til springtests og hoppehøjde](/springtests-hoppehoejde/).
* **Vurder din ankelstabilitet:** Udfør [Enkeltbensstand og Stork-test](/enkeltbensstand-stork-test/).

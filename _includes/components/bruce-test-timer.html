Om Bruce Protocol Løbetesten

Standardiseret maksimal belastningstest på løbebånd

TESTENS OPBYGNING:
1. Testen udføres på et motoriseret løbebånd.
2. Hvert trin varer nøjagtigt 3 minutter.
3. For hvert trin øges både hastigheden (km/t) og hældningen (%).
4. Testen fortsætter indtil atleten når udmattelse og stopper.
